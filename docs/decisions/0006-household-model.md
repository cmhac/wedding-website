# 0006: Household and party model

Status: accepted (2026-10-19)

The household is the unit that is invited and emailed, with exactly one
responder (the contact email). Invitations are per guest per event. Plus-ones
are placeholder guest rows, as many as the household's allowance, which the
responder names. The welcome party and rehearsal are ordinary events marked
optional and grouped under the wedding weekend.

Why: it expresses every case in the spec (rehearsal-only guests, different event
lists within a household, optional events) without special cases. No children
are invited, so there is no child or infant distinction.
