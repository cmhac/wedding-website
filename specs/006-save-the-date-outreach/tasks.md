# Tasks: Save the date outreach

**Input**: Design documents from `specs/006-save-the-date-outreach/` (plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md)

**Prerequisites**: plan.md and spec.md (both present). The constitution requires tests first, so every implementation task is preceded by its failing test in the same phase.

**Tests**: required (constitution principle I). Jest and React Testing Library under `__tests__` next to the source; pgTAP under `supabase/tests/database/`. No test touches the network. pgTAP tests need Docker and the local Supabase (`npm run test:db`); they are written here and run where Docker exists.

**Format**: `- [ ] T### [P?] [US#?] Description with file path`. `[P]` means it can run in parallel (different files, no unfinished dependency).
