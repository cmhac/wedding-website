# Design mockups

Six artboards drawn on the design canvas (https://claude.ai/artifact/1MYURQzxVv9kyforgKShai, private to the couple). The `.dc.html` files here are static copies for reference; they need the canvas runtime to open, so read them as markup and styles. They use the console's own colours and type from `src/app/(admin)/admin.css` and no design system.

| File                    | Shows                                                         |
| ----------------------- | ------------------------------------------------------------- |
| `Main.dc.html`          | The full banner above page content, nav link with a count     |
| `GuideConsole.dc.html`  | The guide on a step set in the console (wedding event)        |
| `GuideOutside.dc.html`  | The guide on a step set outside it (email sending)            |
| `Paused.dc.html`        | The compact reminder after leaving the guide                  |
| `Done.dc.html`          | Required steps done, recommended group still open             |
| `Mobile.dc.html`        | Phone width: banner and bottom-sheet guide                    |
